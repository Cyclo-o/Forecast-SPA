# Forecast-SPA

A single-page application to display weather forecasts.

## Quick start

1. Install dependencies
   - npm: `npm install`
   - yarn: `yarn`

2. Run locally
   - `npm run dev` or `npm start` (replace with the start command your project uses)

3. Build
   - `npm run build`
